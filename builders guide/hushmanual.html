04 — Developer Usage

Tooling Config

Paste the RPC URL into your preferred tool.

networks: {
  hush: {
    url: "https://rpc.hushnetworks.in",
    chainId: 47755852468,
    accounts: [process.env.PRIVATE_KEY]
  }
}
forge script script/Deploy.s.sol \
  --rpc-url https://rpc.hushnetworks.in \
  --broadcast
curl -X POST https://rpc.hushnetworks.in \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0",
       "method":"eth_chainId",
       "params":[],"id":1}'
05 — RPC Notes

Usage Notes

Things to keep in mind when integrating.

  • Endpoint is for programmatic use — not browser navigation
  • Use methods like eth_chainId, eth_blockNumber, eth_sendRawTransaction
  • A blank page at the RPC URL is not an error
  • If a script fails, test with a small JSON-RPC POST first
